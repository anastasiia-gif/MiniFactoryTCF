# 📁 Project Overview – Mini Factory

Welcome to the repository for the Mini Factory educational safety and system enhancement project. This README will help you navigate the folder structure and understand where to find essential project materials.

---

## 📄 Documents Folder

This folder contains all key written reports and planning documents.

- **🔹 REP_MiniFactory** – *Recommended starting point*. This is the main report from the previous internship student and provides a comprehensive overview of the project, including safety implementation, system design, and educational use.
- **🔹 Proeve van Bekwaamheid** – An MBO-level student report referenced by the REP, with additional background and system wiring insights.
- **🔹 PoA (Plan of Approach)** – The initial planning and scoping document from the internship project.
- **🔹 RAR (Risk Assessment Report)** – Details the system’s safety risks and mitigation strategies. Most content is included in the REP.
- **🔹 URS (User Requirements Specification)** – Defines the functional and safety requirements of the system. Mainly embedded in the REP and PoA.

---

## 🛠️ Mechanical Folder

Contains all mechanical CAD files and drawings for system improvements and safety implementations.

- For **part naming and assembly clarity**, please read the [**Assembly Guide**](https://docs.google.com/document/d/1loEIo7aQlHCNWvezpFuo1hC8qLYhPY-sCpMDtRe_vX0/edit?usp=sharing).  
  This guide explains which file corresponds to which physical part and how components fit together.

## 📘 Manuals Folder

This includes:

- **Original Bosch Rexroth manuals** for the base Mini Factory system.  
  ⚠️ *Most documents are in German; some have been AI-translated to English for convenience.*
- **Electrical Datasheets** for both the original system and components proposed in the safety upgrade (e.g., relays, contactors, RCDs).
